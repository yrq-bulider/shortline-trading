# 短线操作 v1

> A 股 4 维评分短线筛选器 · 当前胜率 ~50%，目标 ≥ 70%

每天盘后跑一次，输出次日 TOP3 股票 + T+1/T+0 双模式支持 + 自动回测归因。

## 4 维评分体系

| 维度 | 权重 (T+1 / T+0) | 说明 |
|------|------------------|------|
| 技术面 | 30 / 50 | 趋势、量价、形态 |
| 业绩面 | 25 / 15 | 一季报同比、扣非净利润 |
| 资金面 | 20 / 25 | 主力净流入、北向资金 |
| 消息面 | 25 / 10 | 定增/并购/订单加分，减持/亏损减分 |

板块联动 + 智能去重 + 业绩地雷排除（详见 `QUICKSTART.md`）。

## 快速开始

```bash
# 装依赖
pip install baostock akshare pandas numpy

# 每日扫描
python daily.py

# T+0 模式（ETF/可转债）
python daily.py --t0

# 跑回测
python daily.py --backtest
```

完整说明见 **[QUICKSTART.md](./QUICKSTART.md)**。
