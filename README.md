# 短线操作 v1

> A 股 5 维评分短线筛选器(v2.0 · 2026-06-15 加机构行为维) · 当前胜率 ~50%，目标 ≥ 70%
> 每天盘后跑一次，输出次日 TOP3 + 自动回测归因 + **证伪门**（反确认偏误）。

---

## 快速开始

```bash
# 装依赖
pip install baostock akshare pandas numpy

# 每日扫描（默认 T+1 模式，A 股股票）
python daily.py

# T+0 模式（ETF / 可转债）
python daily.py --t0

# 只跑回测（看历史胜率 + 4 维归因）
python daily.py --backtest
```

## 5 维评分体系 (v2.0 · 2026-06-15 加)

| 维度 | 权重 T+1 / T+0 | 含什么 | 数据源 |
|------|------|------|------|
| **技术面** | 20 / 35 | MA5/10/20 排列、MACD 红柱、RSI、布林带位置、放量突破、量价共振 | baostock 日 K |
| **业绩面** | 15 / 10 | 一季报扣非净利润同比、业绩高增加分、**业绩雷区（-30%）直接淘汰** | akshare `stock_yjbb_em` |
| **资金面** | 25 / 30 | 5 日主力净流入 + **主力分单(特大/大/中/小单)** + 北向 3 日 + 龙虎榜 + 量比 | akshare 多源 |
| **消息面** | 20 / 10 | 公告(减持/重组/订单等)+ 新闻情感 | akshare 多源 |
| **机构行为 (新)** | **20 / 15** | **大宗折价 + 卖方席位 + 融资融券变化 + 股东户数变化 + 解禁压力** | **akshare 多源** |

每个子维度 0-100 分，加权得**综合分 0-100**。综合分 ≥ 75 = 强候选，≥ 65 = 备选。

> **资金面内部子分权重**:主力5日 0.20 + 主力分单 0.30 + 北向3日 0.20 + 龙虎榜 0.20 + 量比 0.10
> **机构行为子分权重**:大宗 0.30 + 融资 0.25 + 股东户数 0.25 + 解禁 0.20

**v2.0 关键变化**(相对 v1.3):
- 资金面从 1 子扩到 5 子(新增主力分单细粒度 + 北向/龙虎/量比从其他维迁入)
- 消息面从 4 子缩到 2 子(只留公告 + 新闻情感)
- 新增第 5 维"机构行为"(占比 20%):识别主力出货 + 杠杆撤退 + 筹码分散 + 解禁卖压
- 资金面权重 20→25,消息面权重 25→20,技术/业绩面缩 10pp 让位给机构维

v1.3 4 维评分仍保留(用于回测对比),TOP3 报告同时展示 4 维 + 5 维子分。

## 核心特性

- **业绩地雷排除**——一季报归母净利润同比 -30% 自动淘汰，从源头剔除"看起来便宜实则烂账"的票
- **智能去重**——近 3 日推荐过的票跳过（防"信号耗尽"重复推）
- **板块联动**——同行业当日均涨跌 + MA5 方向作为板块强度，技术分 × 0.7 + 板块分 × 0.3 加权
- **T+1 / T+0 双模式**——权重、止损/止盈、操作规则、报告模板全套自动切换
- **自动回测 + 归因**——拉历史评分 + 次日实际涨跌，算胜率 + 各维度相关性 + 消融实验 + 调参建议
- **证伪门**——每只 TOP3 强制输出 3 条"明日跌的理由"，逼先想反面再下单（详见下节）
- **HTML 可视化报告**——4 维子分柱状图 + TOP3 卡片 + 归因表 + 调参清单

## 证伪门（2026-06-10 加 · 借鉴 Serenity 反确认偏误）

### 解决什么问题

老报告只列利好（综合分高 + 信号亮 + 业绩好），用户看完容易"想买"。这是教科书级**确认偏误**——大脑只接收支持已倾向结论的信号，回避反面证据。

证伪门把怀疑机制**内置进报告**：每只 TOP3 顶部强制呈现 3 条"明日可能跌的理由"，排在 4 维子分（bull 信息）**之前**，顺序锁死。

### 9 条证伪条件（按严重度排序）

| 条件 | 触发阈值 | 严重度 |
|------|---------|------|
| RSI 严重超买 | RSI ≥ 75 | 高 |
| 正乖离过大 | bias ≥ 8% | 高 |
| MACD 柱已转弱 | macd_bar ≤ 0 | 高 |
| 贴近布林上轨 | price ≥ bb_upper × 0.98 | 中 |
| 业绩面薄弱 | earn 分 ≤ 40 | 中 |
| 资金面薄弱 | flow 分 ≤ 40 | 中 |
| 板块退潮 | sector 分 ≤ 35 或均涨跌为负 | 中 |
| RSI 偏超买 | 70 ≤ RSI < 75 | 低 |
| 消息真空 | news 分 ≤ 30 | 低 |
| 信号共振不足 | signal_count ≤ 1 | 低 |

### v2.0 新增 3 条机构流出证伪(v2.0 · 2026-06-15 加)

| 条件 | 触发阈值 | 严重度 |
|------|---------|------|
| **大宗折价过高** | 近 30 日大宗平均折价率 ≥ 10% | 高 |
| **融资余额骤降** | 7 日融资余额变化率 ≤ -10% | 中 |
| **解禁压力** | 30 日内累计解禁 ≥ 5% 流通 | 中 |

机构流出口径:派生自已抓的 `_INST_DF` 4 张表(大宗/融资/股东户数/解禁),与 v1.3 9 条并列展示。`margin_change` 留 v2.0.1 接历史对比。

命中越多 → 红线越亮 → 越要小仓位 / 跳过。

### 不会引入新数据源

9 个条件全部派生自已抓的 K 线指标 + 4 维子分 + 板块数据，**零新依赖**。符合"稳准优先"原则（baostock 限流场景下不增加 IO）。

## 涨停板候选池 + 大盘情绪门(v1.3 · 2026-06-14 加)

两个新机制,放在 4 维评分之上做"二次过滤 + 仓位调节":

### 大盘情绪门(仓位乘数)

每日预拉涨停股池 + 市场活跃度,分 4 档:

| 档位 | 触发条件 | 仓位乘数 |
|------|----------|----------|
| hot  | 连板≥30 且 涨停≥80 | 1.0 |
| normal | 其余 | 0.8 |
| cool | 连板<10 | 0.5 |
| cold | 涨停<30 | 0.2 |

优先级:cold > cool > hot > normal。TOP3 的 `position_pct` 自动乘上对应乘数。
数据拉取失败 → tier='normal'/multiplier=1.0,不影响 v1.2 行为。

### 涨停板候选池(首板小盘)

每日扫描后,从涨停股池筛主板首板小盘候选:

- 主板 00xxxx / 60xxxx
- 单价 ≤30 元
- 流通市值 ≤300 亿
- 封板时间 ≤14:30
- 炸板次数 ≤5
- 连板数 =1(只要首板)
- 4 维综合分 ≥60
- 业绩雷区已过(`compute_falsification_signals` 为空)

按综合分降序输出 TOP5,落到 CLI 报告 + HTML 报告尾部。
涨停池为空(非交易时段/休市) → 跳过,不报错。

## 自动回测 + 归因（看 4 维到底有没有用）

跑 `python daily.py --backtest`，至少 20 笔历史数据后看：

- **相关性表**：每个子分 vs 次日收益的相关系数（`|r| ≥ 0.3` = 强有效，`|r| < 0.1` 且胜率差 < 5% = 噪声，建议降权）
- **消融实验**：4 维全开 vs 只看技术 / 业绩 / 资金 / 消息——哪种胜率最高
- **自动调参建议**：基于相关性强弱，建议"哪个维度该加权重、哪个该降"

如果"单维度" > "4 维综合" → 维度加权有问题，按建议调 `WEIGHT_*` 常量。

## 适用边界（诚实层）

**适用**：
- A 股小市值 / 中等市值题材股
- T+1 隔夜 + T+0 ETF/可转债 日内波段
- 短线轮动驱动的市场（题材热点、政策催化、业绩预喜）

**不适用 / 判断力弱**：
- 超大盘股（已被机构充分定价，4 维信号失真）
- 长持（5 年以上 compounder 类，本框架是短线工具）
- 极端单边市（系统性风险面前所有 alpha 因子失效）
- 没有历史评分数据（前 5-10 个交易日只跑扫描，别动手）
