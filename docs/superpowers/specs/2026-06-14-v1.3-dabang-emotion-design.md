## 1. 背景与目标

### 1.1 现状

`筛选明日股票_v1.py` v1.2 已经完成：
- 4 维评分（技术 30 / 业绩 25 / 资金 20 / 消息 25）
- 证伪门 9 条
- P1 先行信号：北向 3 日 + 龙虎榜机构席位加成

**缺口**：
- 没有"大盘级"风控开关 — 4 维评分高的票，遇到大盘冰点也照样推
- 没有 A 股短线核心 alpha — 涨停板战法（首板 / 一进二 / 连板天梯）

### 1.2 目标

把 A 股短线的两个核心信号纳入 v1.3，**保持 4 维与证伪门完全不动**：

- **大盘情绪门**：根据涨停 / 连板 / 跌停家数判定 3 档情绪（热 / 冷 / 冰），自动调仓位倍率
- **打板候选池**：基于今日首板筛选"一进二"候选名单，作为 TOP3 之外的补充推荐

### 1.3 非目标

- 不改 4 维权重（30/25/20/25 保持）
- 不改证伪门 9 条
- 不引入第 5 个评分维度（打板候选是独立名单，不进 4 维）
- 不动 baostock / 已有 8 个 akshare wrapper
- 不做端到端实盘对接

### 1.4 关键约束（来自项目）

- ✅ 稳准 > 效率（不并发，失败必降级）
- ✅ 文件 < 2000 行（v1.py 主程序）
- ✅ 失败必降级到上版本（v1.2）行为
- ✅ 主程序永远可跑（`python -m py_compile` + `import` 必过）

def fetch_zt_pool(date: str | None = None) -> pd.DataFrame | None:
    """涨停股池(21 字段:连板数/首封时间/炸板次数/封单资金/涨停统计 X/Y 等)。
    date 为 None 时用今天;ak.stock_zt_pool_em 返回当日全市场涨停股 ~50-100 条。"""
    import akshare as ak
    from datetime import datetime
    if date is None:
        date = datetime.now().strftime('%Y%m%d')
    return call_with_fallback(
        attempts=[(ak.stock_zt_pool_em, {'date': date})],
        cache_key=f'zt_pool_{date}',
        timeout=10,
        retries=1,
    )


def fetch_market_activity() -> pd.DataFrame | None:
    """乐咕乐股市场活跃度(涨停/跌停/真实涨/真实跌/平 5 类计数)。
    ak.stock_market_activity_legu 返回 5 行 KV 表。"""
    import akshare as ak
    return call_with_fallback(
        attempts=[(ak.stock_market_activity_legu, {})],
        cache_key='market_activity',
        timeout=10,
        retries=1,
    )

### 2.3 `market_emotion.py` 新模块

**职责**：吃涨停股池 + 市场总览 → 输出 3 档情绪标签 + 仓位乘数

```python
"""v1.3 大盘情绪门 — 连板/涨停/跌停三档判定。

设计原则:失败时返回 'normal' + 倍率 1.0,绝不让主流程挂。
"""
import pandas as pd


EMOTION_THRESHOLDS = {
    'hot':  {'lianban_count': 30, 'zt_count': 80},   # 任一满足 = 热
    'cool': {'lianban_count': 10},                    # 连板 < 10 = 冷
    'cold': {'zt_count': 30},                         # 涨停 < 30 = 冰
}

POSITION_MULTIPLIER = {
    'hot':    1.0,
    'normal': 0.8,
    'cool':   0.5,
    'cold':   0.2,
}


def compute_emotion_tier(zt_pool_df, market_activity_df) -> dict:
    """
    输入:
        zt_pool_df: fetch_zt_pool() 返回(可 None)
        market_activity_df: fetch_market_activity() 返回(可 None)
    输出 dict:
        tier: 'hot'/'normal'/'cool'/'cold'
        multiplier: 0.2-1.0
        zt_count: 今日涨停家数
        lianban_count: 今日连板家数(连板数 >= 2)
        dt_count: 今日跌停家数
        reason: 中文描述
    """
    if zt_pool_df is None or zt_pool_df.empty:
        return {
            'tier': 'normal',
            'multiplier': 1.0,
            'zt_count': 0,
            'lianban_count': 0,
            'dt_count': 0,
            'reason': '涨停池拉取失败,降级 normal/x1.0',
        }

    zt_count = len(zt_pool_df)
    lianban_col = next((c for c in zt_pool_df.columns if '连板' in c), None)
    if lianban_col:
        lianban_count = int((pd.to_numeric(zt_pool_df[lianban_col], errors='coerce') >= 2).sum())
    else:
        lianban_count = 0

    dt_count = 0
    if market_activity_df is not None and not market_activity_df.empty:
        item_col = next((c for c in market_activity_df.columns if c in ('item', 'name', '指标')), None)
        value_col = next((c for c in market_activity_df.columns if c in ('value', 'count', '数值')), None)
        if item_col and value_col:
            dt_row = market_activity_df[market_activity_df[item_col].astype(str).str.contains('跌停', na=False)]
            if not dt_row.empty:
                dt_count = int(pd.to_numeric(dt_row[value_col].iloc[0], errors='coerce') or 0)

    # 判定优先级:冰 > 冷 > 热 > normal
    if zt_count < EMOTION_THRESHOLDS['cold']['zt_count']:
        tier = 'cold'
    elif lianban_count < EMOTION_THRESHOLDS['cool']['lianban_count']:
        tier = 'cool'
    elif (lianban_count >= EMOTION_THRESHOLDS['hot']['lianban_count']
          or zt_count >= EMOTION_THRESHOLDS['hot']['zt_count']):
        tier = 'hot'
    else:
        tier = 'normal'

    return {
        'tier': tier,
        'multiplier': POSITION_MULTIPLIER[tier],
        'zt_count': zt_count,
        'lianban_count': lianban_count,
        'dt_count': dt_count,
        'reason': f"{tier}|涨停{zt_count}|连板{lianban_count}|跌停{dt_count}|仓位x{POSITION_MULTIPLIER[tier]}",
    }
```

### 2.4 `dabang_pool.py` 新模块

**职责**：吃今日涨停股池 → 输出"一进二"候选名单

**实战标准**（来源：CSDN 量化派 + 雪球短线大佬）：
- 股价 ≤ 30 元
- 总市值 ≤ 300 亿
- 最后封板时间 ≤ 14:30（早封更稳）
- 炸板次数 ≤ 5
- 连板数 == 1（首板专门做一进二）
- 仅主板（00xxx + 60xxx）
- 本项目特有：4 维综合分 ≥ 60（避免烂票） + 业绩雷区已过滤

```python
"""v1.3 打板候选池 — 一进二接力名单。"""
import pandas as pd


DABANG_FILTERS = {
    'price_max':       30.0,
    'mv_max_yi':       300.0,    # 单位:亿元
    'feng_time_max':   '14:30',  # 字符串比较
    'zhaban_max':      5,
    'lianban_eq':      1,        # 首板专门做一进二
    'score_min':       60,       # 4 维综合分
}


def compute_dabang_candidates(zt_pool_df, score_dict, top_n=5) -> list:
    """
    输入:
        zt_pool_df: fetch_zt_pool() 今日涨停
        score_dict: {code6: {'composite_score':..,'leiqu':bool,...}} 来自 4 维评分缓存
        top_n: 最多返回 N 只
    输出 list[dict]:
        每个 dict: {code, name, price, mv_yi, lianban, feng_time, zhaban,
                    composite_score}
    """
    if zt_pool_df is None or zt_pool_df.empty:
        return []

    df = zt_pool_df.copy()
    # 列名兼容(akshare 版本差异),用 next() 模糊匹配
    code_col    = next((c for c in df.columns if '代码' in c), None)
    name_col    = next((c for c in df.columns if '名称' in c), None)
    price_col   = next((c for c in df.columns if '最新价' in c), None)
    mv_col      = next((c for c in df.columns if '总市值' in c), None)
    feng_col    = next((c for c in df.columns if '最后封板时间' in c), None)
    zhaban_col  = next((c for c in df.columns if '炸板次数' in c), None)
    lianban_col = next((c for c in df.columns if '连板' in c), None)

    if not code_col or not name_col:
        return []  # 关键列丢失,降级

    df['_code6'] = df[code_col].astype(str).str.zfill(6)

    # 主板过滤
    df = df[df['_code6'].str.startswith(('00', '60'))]

    # 数值过滤(防 NaN)
    if price_col:
        df[price_col] = pd.to_numeric(df[price_col], errors='coerce')
        df = df[df[price_col] <= DABANG_FILTERS['price_max']]

    if zhaban_col:
        df[zhaban_col] = pd.to_numeric(df[zhaban_col], errors='coerce').fillna(0)
        df = df[df[zhaban_col] <= DABANG_FILTERS['zhaban_max']]

    if mv_col:
        df[mv_col] = pd.to_numeric(df[mv_col], errors='coerce') / 1e8  # 转亿
        df = df[df[mv_col] <= DABANG_FILTERS['mv_max_yi']]

    if lianban_col:
        df[lianban_col] = pd.to_numeric(df[lianban_col], errors='coerce').fillna(0)
        df = df[df[lianban_col] == DABANG_FILTERS['lianban_eq']]

    if feng_col:
        # akshare 返回的封板时间格式有 '141500' 或 '14:15:00',先归一化
        feng_norm = df[feng_col].astype(str).str.replace(':', '').str[:4]
        df = df[feng_norm <= DABANG_FILTERS['feng_time_max'].replace(':', '')]

    # 4 维 + 业绩雷区
    candidates = []
    for _, row in df.iterrows():
        c6 = row['_code6']
        info = score_dict.get(c6) if score_dict else None
        if info is None or info.get('leiqu'):
            continue
        if info.get('composite_score', 0) < DABANG_FILTERS['score_min']:
            continue
        candidates.append({
            'code':            c6,
            'name':            row[name_col],
            'price':           float(row[price_col]) if price_col else None,
            'mv_yi':           float(row[mv_col]) if mv_col else None,
            'lianban':         int(row[lianban_col]) if lianban_col else 1,
            'feng_time':       str(row[feng_col]) if feng_col else None,
            'zhaban':          int(row[zhaban_col]) if zhaban_col else 0,
            'composite_score': info['composite_score'],
        })

    candidates.sort(key=lambda x: -x['composite_score'])
    return candidates[:top_n]
```

### 2.6 错误处理矩阵

| 失败点 | 行为 | 4 维 / 仓位影响 |
|---|---|---|
| `fetch_zt_pool` 失败 | `_EMOTION = normal/x1.0`，候选池 = `[]` | 仓位不变 |
| `fetch_market_activity` 失败 | `dt_count = 0`，照常算情绪 | 仓位按涨停+连板算 |
| 涨停股池列名变化（如 `炸板次数` 字段消失） | 该过滤项跳过，宽松通过 | 候选可能多但不挂 |
| `score_dict[code]` 不存在 | 跳过该票 | 不进候选 |
| 业绩雷区 | 跳过该票 | 不进候选 |
| 关键列（代码 / 名称）缺失 | 返回 `[]` | 候选空 |
| 节假日 / 周末跑 | 涨停池空 → 候选空 → 情绪 normal | 全降级 |

## 6. 风险与回滚

### 6.1 风险

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| `ak.stock_zt_pool_em` 接口改版 / 列名变化 | 中 | 候选池为空 | 列名 `next()` 模糊匹配 + 失败兜底 |
| `ak.stock_market_activity_legu` 返回结构变化 | 中 | 跌停数 = 0 | 不阻塞，情绪门用涨停+连板兜底 |
| 涨停股池在盘中（未收盘）拉取数据不完整 | 高 | 数据假象 | daily.py 默认盘后跑，README 强调"15:00 后再跑" |
| 一进二历史炸板率上升（AI 量化挤压） | 中 | 候选胜率下降 | 候选池只是"建议"不是"必买"；用户可关掉显示 |
| 节假日 / 周末跑 → 涨停池为空 | 低 | 全部为空 | 失败降级正常工作 |
| v1.py 主程序 ~2134 行 → 加 ~80 行 → ~2210 | 中 | 突破 2000 上限 | 70%+ 逻辑在 2 个新子模块；如膨胀触发拆分，后续再做 backtest_dimension_attribution 等抽离 |
| 情绪门倍率 x0.2 让冰档时几乎不开仓 | 设计意图 | 用户可能想强行操作 | README §调参 注明改 `POSITION_MULTIPLIER` |
