# A股量化短线工具箱

专为A股短线交易者打造的量化工具箱，集成数据获取、策略回测、GitHub项目索引功能。

## 快速开始

### 安装依赖

```bash
pip install baostock rqalpha akshare pandas numpy matplotlib
```

### 基础命令

| 命令 | 功能 | 示例 |
|------|------|------|
| `/获取数据` | 下载股票数据 | `/获取数据 600519 2024-01-01 2025-06-01` |
| `/获取分钟数据` | 下载分钟数据 | `/获取分钟数据 000001 5min 2025-06-01` |
| `/策略` | 选择策略模板 | `/策略 突破策略` |
| `/设置` | 设置策略参数 | `/设置 threshold=5%` |
| `/回测` | 运行回测 | `/回测` |
| `/图表` | 生成回测图表 | `/图表` |
| `/找项目` | 搜索GitHub项目 | `/找项目 量化交易` |
| `/项目详情` | 查看项目详情 | `/项目详情 vnpy` |
| `/帮助` | 显示帮助信息 | `/帮助` |

## 内置策略

1. **突破策略** - 价格/成交量突破均线
2. **均线策略** - MA5/MA20金叉死叉
3. **打板策略** - 涨停板效应
4. **量价策略** - 量增价涨

## 数据源

- baostock（主要）- 免费、A股专用
- akshare（备用）- 更全面

## 回测框架

rqalpha - 聚宽出品，专为A股优化
